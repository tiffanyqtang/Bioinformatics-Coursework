# Transcriptomics

This folder contains my work for **Transcriptomics** at NYU Tandon School of Engineering. The course focuses on transcriptomic technologies such as RNA-seq and microarrays, emphasizing statistical analysis, data visualization, and biological interpretation using the R programming language.

## Contents

- **Homework 1**: Introduction to transcriptomics and using R Studio to read in data and create visualizations.
- **Homework 2**: Extracted p-values using loops, applied linear modeling (lm) and FDR correction, and interpreted differential expression results based on significance thresholds.
- **Homework 4**: Differential expression analysis and GO enrichment analysis.

Each assignment folder has the R script I submitted for grading. All files were done in an R studio markdown notebook.
